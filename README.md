# Google AI Edge Gallery - Java + XML Edition

**Offline-ready Android app inspired by Google AI Edge Gallery**

## Features
- AI Chat
- Voice Input
- Text-to-Speech
- Ask Image
- Media Search
- Video Support
- Prompt Lab
- Model Manager
- Agent Skills
- Tiny Garden
- Mobile Actions
- Full Java + XML Architecture

## Build
- Open in Android Studio
- Sync Gradle
- Build > Build APK(s)

## APK Output
- app/build/outputs/apk/debug/app-debug.apk
